# 数据采集流程

这些脚本用于复现本次数据获取方式。公开接口可能变化，聚合统计也会随新比赛增长；重新采集并不保证得到2026年10月20日的相同快照。

已交付的 `dist/data/snapshot.json` 是固定快照，应用不会后台更新它。

运行 `node tools/collect.cjs` 只下载到 `.cache/`，不覆盖交付快照。人工检查赛事、日期、比赛服版本、异常动作和新公告后，运行 `node tools/compile.cjs` 更新数据，再运行测试和离线打包。编译器中的版本标签与日期是本次已核验事实，跨版本更新时必须重新核验和修改；不能仅修改采集时间。

采集包括官方英雄列表、2026年度总决赛逐局数据、英雄统计和英雄资料。`verified-version.json` 为人工核验的官方规则/版本摘要，附原文链接。没有使用王者营地登录接口或个人会话。
