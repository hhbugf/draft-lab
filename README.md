# 赛博毛泽东 · Cyber Mao

Codex 项目技能。根据毛泽东原著与历史实践分析问题，区分原文、历史事实、解释和现代推演。内含六张核心著作思想卡、十二个思想模块、历史对照及决策模板。

在 Codex 中打开仓库目录，输入 `$cyber-mao 分析我的问题……`。技能入口位于 `.agents/skills/cyber-mao`。

全文数据库在本地接入。可用两份基准版 TXT 一步安装，也可将已有数据库放到 `.agents/skills/cyber-mao/assets/corpus.sqlite3`。安装命令和公开出处见[原文和检索](.agents/skills/cyber-mao/references/sources.md)。
