## 12个思想模块：历史依据与现代调用

下表的“现代调用”都是方法迁移，不是毛泽东对当代问题作出的具体指示。S编号对应文末来源。

| 模块 | 已核查的历史依据 | 现代调用 | 需要防止的误用 |
| --- | --- | --- | --- |
| 实事求是 | S09第三部分：研究客观情况及其联系 | 把事实、自述、假设分开，检查解释能否覆盖材料 | 用个人感受冒充事实；用权威代替证据 |
| 调查研究 | S02第七节：纲目、参与者、深入调查和记录 | 围绕决策问题访谈，交叉核对，保留原始记录 | 把一次访谈当总体；用调查无限拖延决策 |
| 矛盾分析 | S05第四、六节：主次关系与对抗形式 | 找当前制约目标的关键关系，列替代解释和转化条件 | 把任务优先级直接等同于哲学矛盾；把分歧全部敌对化 |
| 实践认识 | S04认识与实践的往复关系 | 提出假设、行动检验、记录结果、修正解释 | 只行动不总结；一次成功即认定普遍有效 |
| 群众路线 | S08第四、六段：意见集中、实施与检验 | 听取直接受影响者，形成方案后返回现场验证 | 将群众路线简单等同流量、投票或迎合顾客 |
| 战略与战术 | S03第一章第三、四节、第五章第六节 | 判断全局目标，选择能形成局部优势的重点投入 | 把集中投入理解成无条件押上全部资源 |
| 持久战与运动战 | S06双方条件、阶段变化及主动性；S03第五章 | 判断资源能否支撑、时间能否改善能力及选择空间 | 把长期坚持当成必胜理由；照搬军事手段 |
| 统一战线 | S01利益与社会位置；S07合作中的互让 | 找共同目标、利益分歧、互惠条件和合作边界 | 将商业合作等同政治统一战线；将所有合作都解释成权谋 |
| 独立自主 | S07统一性与独立性的关系 | 识别关键能力和依赖，保留履约能力、判断能力与替代选择 | 拒绝必要合作；把守约责任说成丧失自主 |
| 批评与自我批评 | S13结尾对批评目的的说明 | 检查错误假设、流程与责任，用改进方案完成复盘 | 用羞辱代替分析；领导只要求他人认错 |
| 组织与执行 | S08第三、七、八段；S10工作方法 | 明确负责者与协调机制，确定重心，用数据检查执行 | 把纪律化为盲从；把多个任务同时宣称为唯一重心 |
| 辩证思维 | S05特殊性与条件转化；S11资源关系 | 检查部分与整体、当前与长期的相互影响和代价 | 只说“两面性”；面对证据仍拒绝作有条件的取舍 |

## 已核查的原著关键段落

以下为概括性阅读卡，不含完整原文。所有条目均为“关键段落已核查”；未确认网页底本版次，不提供纸本页码。

### S01 中国社会各阶级的分析

- 题下时间：1925-12-01；《毛泽东选集》第一卷。
- 核查位置：开篇及中产阶级分析。
- 内容：依据社会经济地位和革命态度辨析各类力量，注意同一阶级态度的矛盾性。
- 迁移边界：可启发利益分析；不能直接套用原文阶级分类给当代每个人定性。
- [原文网页](https://www.12371.cn/2012/11/19/ARTI1353313414202316.shtml)

### S02 反对本本主义

- 题下时间：1930-05；《毛泽东选集》第一卷。
- 核查位置：第一、三、七节。
- 内容：反对脱离情况的书本依赖，说明讨论式调查、调查纲目、深入调查及自行记录。
- 迁移边界：具体人员数量与调查形式来自当时工作，不能直接当成现代抽样方法。
- [原文网页](https://www.12371.cn/2012/08/10/ARTI1344592797863461.shtml)

### S03 中国革命战争的战略问题

- 题下时间：1936-12；《毛泽东选集》第一卷。
- 核查位置：第一章第一、三、四节；第五章第六节。
- 内容：分别研究一般与特殊规律、全局与局部关系，并根据侦察判断调整计划；集中兵力谋求局部优势。
- 迁移边界：资源聚焦可以作类比，军事消灭、作战方式不直接用于现代民事关系。
- [原文网页](https://www.shkjdw.gov.cn/c/2014-05-13/489640.shtml)

### S04 实践论

- 题下时间：1937-07；《毛泽东选集》第一卷。
- 核查位置：实践与认识的关系、结尾循环论述。
- 内容：从实践形成认识，并把认识返回实践检验和发展。
- 迁移边界：一次得到预期结果仍可能存在偶然性与其他解释；当代实验须核对这些因素。
- [原文网页](https://news.12371.cn/2017/08/29/ARTI1504001411770206.shtml)

### S05 矛盾论

- 题下时间：1937-08；《毛泽东选集》第一卷。
- 核查位置：第三、四、六节。
- 内容：分析特殊条件、主次关系、方面之间的关系及转化；对抗只是矛盾斗争的一种形式。
- 迁移边界：把它作为分析框架，不凭概念本身断言某个现实原因已获证明。
- [原文网页](https://news.12371.cn/2017/08/29/ARTI1504001209326173.shtml)

### S06 论持久战

- 题下时间：1938-05；《毛泽东选集》第二卷。
- 核查位置：第10—12、59—62、75—80段相关论述。
- 内容：从双方条件出发判断战争发展，并讨论能动性、局部行动和总体力量变化的关系。
- 迁移边界：时间本身不产生优势，必须说明资源、学习和行动如何改变条件；不能由此推断创业必胜。
- [原文网页](https://www.12371.cn/2012/11/18/ARTI1353205436991290.shtml)

### S07 统一战线中的独立自主问题

- 题下时间：1938-11-05；《毛泽东选集》第二卷。
- 核查位置：帮助与让步、统一性与独立性的论述。
- 内容：围绕抗日合作，讨论互助互让以及合作中保留相对独立性的关系。
- 迁移边界：现代合作的边界由具体契约、职责和当代制度界定，不能用历史论述否定履约义务。
- [原文网页](https://www.shkjdw.gov.cn/c/2014-05-13/489656.shtml)

### S08 关于领导方法的若干问题

- 题下时间：1943-06-01；《毛泽东选集》第三卷。
- 核查位置：第二、三、四、六、七、八段。
- 内容：个别指导与一般号召结合，形成骨干并联系群众，集中意见后在行动中检验，确定阶段工作重心。
- 迁移边界：用户访谈和小范围试点只是现代类比；原文同时具有党组织领导工作的历史内涵。
- [原文网页](https://www.shkjdw.gov.cn/c/2014-05-13/489698.shtml)

### S09 改造我们的学习

- 题下时间：1941-05-19；《毛泽东选集》第三卷。
- 核查位置：第三部分实事求是论述、第四部分调查主张。
- 内容：研究现实及历史，依据材料寻找联系，用理论回答具体问题。
- 迁移边界：调查材料仍需质量判断；不能把现象堆积本身当作解释。
- [原文网页](https://www.12371.cn/2012/11/19/ARTI1353322284898760.shtml)

### S10 党委会的工作方法

- 时间：1949-03-13；《毛泽东选集》第四卷。
- 核查位置：第七至十一条及篇末所注卷次；日期另由中央纪委网站刊本核对。
- 内容：重视数量分析、会前准备、表达简明、同不同意见者合作及戒骄。
- 迁移边界：委员会领导关系不能直接等同企业组织结构；具体权限须重新设计。
- [原文网页](https://news.12371.cn/2016/02/25/ARTI1456354051355105.shtml)
- [日期核对入口](https://m.ccdi.gov.cn/content/95/d7/8636.html)

### S11 论十大关系

- 题下时间：1956-04-25；《毛泽东文集》第七卷为后续纸本对勘目标，本次未据其纸本核页。
- 核查位置：开篇、第一和第二关系、第五关系。
- 内容：讨论社会主义建设中的资源配置，以及统一领导与地方积极性的关系。
- 迁移边界：可启发整体配置和授权分析；原文经济判断须放在当时条件中理解。
- [开篇网页](https://fuwu.12371.cn/2013/08/14/ARTI1376449049161135.shtml)
- [第五关系网页](https://fuwu.12371.cn/2013/08/14/ARTI1376449049161135_3.shtml)

### S12 关于正确处理人民内部矛盾的问题

- 网页题下时间：1957-02-27；发表稿与原讲话的区别见H03。
- 核查位置：第一节对矛盾性质、处理方式及团结与批评的论述。
- 内容：区别不同性质的矛盾，提出人民内部问题的说服、批评与团结方法。
- 迁移边界：原文对人民与敌人的划分带有特定政治条件，不能直接用于一般职场与人际分歧。
- [原文网页](https://fuwu.12371.cn/2013/08/19/ARTI1376892293655966_all.shtml)

### S13 整顿党的作风

- 题下时间：1942-02-01；《毛泽东选集》第三卷。
- 核查位置：主观主义、理论与经验关系，以及结尾的批评目的。
- 内容：批评教条主义与经验主义的片面性，主张理论实际结合，以纠错改善工作。
- 迁移边界：倡导的批评原则与整风实践中的具体行为、后果应分别核查。
- [原文网页](https://www.shkjdw.gov.cn/c/2014-05-13/489691.shtml)
