# K01 反对本本主义：调查应当改变判断与策略

**历史问题与文本层次。** 本篇所附题解说明其针对红军中的教条主义；正文第五、六节直接讨论社会各阶级的力量与革命策略。因此，它的历史实质包括阶级立场、组织动员和革命任务，并非没有政治目的的一般访谈指南。后来的版本研究记述了文章失而复得、修改审定及收入选集的过程；现行稿不能直接冒充1930年逐字原稿。[V01]

**原文论证的七个环节。**

| 环节 | 原文概括 | 原文定位 |
| --- | --- | --- |
| 发言依据 | 对一个问题的现实与历史不知底里，判断容易失实 | 第一节，1909—1920行 |
| 调查目的 | 通过了解来源与现状取得解决问题的必要材料，反对到任即凭表面现象下结论 | 第二节，1926—1935行 |
| 权威与理论 | 理论及上级指示须结合具体情势理解、落实，书本仍要学习 | 第三节，1941—1950行 |
| 计划的前提 | 仅有认真计划不够，须先了解所指导的实际情况 | 第四节，1956—1967行 |
| 关系与力量 | 不止统计行业和人群，还要研究其内部结构、地位和相互关系，由此确定策略 | 第五节，1973—2012行 |
| 自主认识 | 策略须来自实际经验，既有决议不保证永久适用，农村经验不能代替对城市的了解 | 第五、六节，2012—2031行 |
| 调查技术 | 以问题为中心讨论，选择知情者，准备纲目，深入一个具体问题，亲自参与并记录 | 第七节，2037—2066行 |

**思想结构的解释。** 认识实际情况，辨明关系与力量，再决定策略；执行后出现新情况，就重新调查。核心不是把材料越堆越多，而是让调查结果对判断和行动产生约束。第五节反对只罗列片断现象，是从“收集素材”走向“解释关系”的关键。

**三个不能省略的细节。**

- 原文同时要求学习书本与纠正脱离实际的书本依赖，不能解读为反对理论、专业知识或间接经验（1948行）。
- 调查不必总是地理意义上的“出门”，还可以组织知情者讨论；但亲自理解材料和实际关系的责任不能交给报告替代（1933、2058行）。
- 所附注释转引1931年通知，指出调查本身也要正确。这是编者提供的后续材料，不伪装成1930年正文同一句话（2074行）。

**现代迁移。** 先写清“调查结果会改变哪项选择”，再列关键未知、可能知情者和可核对的记录。把事实、当事人解释和分析者判断分开；比较有差异的情形，检查利益与信息来源。形成一个有依据的暂定判断和行动，而不是无限扩大调查。

**适用边界与纠偏。** 原文的阶级划分、革命阵营和斗争对象须保留历史语境；迁移到当代合作、销售或个人决策时，重新研究制度、职责和利益。原文的调查会人数不是现代统计抽样定律。了解情况有助于解决问题，仍可能受到资源、技术和外部条件限制，不能承诺“一旦调查便必然解决”。

**智能体执行规则。** 信息缺口影响选择时，指出最需要补的证据及取得方式；已有材料足够支持一项可逆行动时，直接提出或执行。不能用“调查研究”掩盖不作判断或只给计划。
