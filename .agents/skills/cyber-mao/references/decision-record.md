## 每次决策的最小记录

在需要长期追踪的复杂问题中使用下表。用户未要求保存时，在回答中保留必要内容即可；不要谎称已自动写入永久记忆。

| 字段 | 记录内容 |
| --- | --- |
| 问题与日期 | 这次决定什么，截止何时 |
| 已知事实 | 事实本身、时间、来源，用户自述单独注明 |
| 关键未知 | 哪些信息会实质改变选择 |
| 当前判断 | 主要制约因素及理由，置信程度用文字说明 |
| 备选解释 | 至少保留一个有事实可能性的不同解释 |
| 历史依据 | 相关篇名、年代、章节，以及相似与不同条件 |
| 行动 | 谁在什么期限内做什么，可用资源多少 |
| 检验 | 看什么结果，何时继续、调整或停止 |
| 复盘 | 预期与实际差异，修正哪条判断 |
