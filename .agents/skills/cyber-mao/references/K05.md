# K05 关于领导方法的若干问题：让一般意见通过个别实施接受检验

**原文出处**：1943年6月1日，为中共中央所写的决定。基准《选集》TXT第9104—9140行，九个编号部分，含附注。

**当时解决什么问题**：整风等工作中，一般号召落空、骨干脱离群众、工作只停留在文件会议上，以及多部门传达导致责任分散和多个中心互相挤占。它是战时政党领导方法文件，带有整风、审查干部等具体政治任务，不能抹去这些内容只当现代管理教材。

**依据什么事实**：主要依据作者对1942年整风成绩与问题的总结，以及机关、学校、部队等组织经验。文件关于“凡有成绩者”等概括，是作者提出的经验判断，未提供可供现代因果识别的样本、对照和统计；不能写成已证明的普遍因果定律。

| 怎样作出判断 | 原文定位 | 条件与边界 |
| --- | --- | --- |
| 先在少数单位具体实施，取得经验，再指导其他单位 | 第二部分，9111行 | 原文建议二三单位属当时安排；现代不机械规定样本数，试点成功仍需跨条件复验 |
| 领导骨干与广泛参与配合，骨干在实际工作中形成并调整 | 第三部分，9113行 | 不能只看领袖意愿，也不能认为自发参与自动带来持续组织 |
| 集中分散意见，解释并付诸行动，再回收经验 | 第四—六部分，9115—9119行 | 群众路线包括认识与组织循环，不等于简单多数投票、客户想什么就做什么或操控舆论 |
| 总负责人和分负责人都知道任务并承担责任 | 第七部分，9121行 | 一元化具有当时的组织背景；现代须另查权限、专业职责和必要制衡 |
| 一定时期有中心工作，并安排其他工作的次序 | 第八部分，9123行 | 主次要根据当地历史与现实决定，不是任何系统都先验地只有一个可证明的关键因素 |

**结论依赖哪些条件**：参与者能提供真实信息，组织能接触实际工作，骨干有能力落实，试点具有一定可比较性，反馈能够修改一般意见，负责人确有调配资源的权限。原文提出循环，不代表每次历史实践都形成了开放反馈。

**适用边界**：现代可迁移为用户访谈、试点、负责人、复盘和扩展条件；必须另行记录沉默者、退出者和失败案例。分类“积极、中间、落后”是原文的政治组织分类，不用它给现实中的异议者贴人格或道德标签。不把群众性审干移植成公司内部互相检举、公开逼供或忠诚测试。

**本卡生成的调用规则**：把一句目标变成“谁，在何时，在哪个对象上，做什么，收集哪些反应”。试点前写出推广条件，试点后查新增资源、选样和领导关注是否使结果不可复制。先修正方案，再决定推广规模。
