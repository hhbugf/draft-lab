# K02 实践论：从材料形成解释，再让解释接受行动检验

**历史问题与版本条件。** 所附题解将矛头指向党内教条主义和经验主义，特别是前者。版本研究说明文章由哲学讲授提纲相关章节发展而来，新中国成立后经历修改；题下1937年7月不等于上传版本每个例证和字句当时均已定型。[V02]

**论证结构。**

| 环节 | 原文概括 | 原文定位 |
| --- | --- | --- |
| 实践基础 | 认识产生于生产、政治、科学文化等社会实践，并带有作者所强调的阶级立场 | 3590—3598行 |
| 感性阶段 | 接触现象、局部和外部联系，尚不足以说明整体规律 | 3602行 |
| 理性阶段 | 对材料进行整理、判断和推理，形成对内部关系和发展规律的解释 | 3604—3606、3618—3624行 |
| 经验的两种来源 | 个人既有直接经验，也有通过他人实践传递的间接经验；并非一切知识都须本人重复发现 | 3606行 |
| 返回实践 | 将认识转为计划和行动，通过实际过程检验和发展理论 | 3626行 |
| 修正方案 | 条件和对象尚未充分显露，方案可能部分或全部不合实际，需要反复调整 | 3628行 |
| 阶段与持续变化 | 对一个具体过程的认识有阶段完成，过程发展又要求更新认识 | 3630—3640行 |

**思想结构的解释。** 经验提供认识的材料，理论整理经验并指导行动，行动再检验理论。两次推进分别是从现象材料形成解释、从解释进入改变对象的实践。只会背原理与只会积累经历，都可能使判断失去依据。

**三个直接约束判断的区分。**

1. “接触过”与“理解了”不同。重复经历不自动形成可靠规律，需要比较和推理（3602—3606、3622行）。
2. “解释得通”与“能指导行动”不同。把一套说法讲圆，尚未完成返回实践的环节（3626行）。
3. “旧方案曾有效”与“当前仍有效”不同。对象和阶段变化时，原有办法可能失配（3630—3634行）。

**原文保留的政治内容。** 本文将认识与无产阶级革命、改造社会及改造主观世界相联系；现代实验设计只能借用其中的方法关系，不能把全文改写成与其历史目标无关的商业效率学说。

**现代迁移。** 在行动前说明：当前解释是什么、它预期产生什么可观察结果、什么证据会削弱它、在何时复盘。行动后区分观察到的结果与对结果的解释，再决定修正假设、执行方式或目标。具体指标、对照和实验设计属于现代补充。

**适用边界与纠偏。** 原文强调实践结果，但现代分析仍须检查偶然因素、执行差异、替代解释和代价。一次收入增加不足以证明全部商业判断正确；一次失败也不足以排除条件不足。既不能用成败简化因果，也不能用“条件还不够”把判断永久保护起来。原文中的历史评价、哲学概括和自然科学例证应分别核查，不能凭其出现在著作中就作为任何学科的终局证明。

**智能体执行规则。** 给出建议时把事实、推断、预期与检验条件分开。用户有真实反馈时更新判断；没有新证据，不宣称认识已经获得实践证实。涉及可靠的间接知识时先核对来源，避免要求用户亲自重复验证一切。
