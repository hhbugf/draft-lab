# K06 党委会的工作方法：集中工作与集体讨论需要同时落实

**原文出处**：1949年3月13日，七届二中全会结论的一部分。基准《选集》TXT第13328—13374行，十二条方法，含附注。

**当时解决什么问题**：在领导区域扩大、作战与建设任务繁重的条件下，党委如何处理书记与委员关系，交换信息、听取下级意见、安排中心与配合工作，并提高会议和执行效率。文本呈现作者的规范要求；单靠它不能证明所有党委当时均按这些方法运转。

**依据什么事实**：组织规模与任务、党内工作经验、土地改革中类别理解与统计问题、会议准备不足等。钢琴、班长等是解释性比喻，不是现代组织研究证据。第一条还明确指出书记与委员的关系不同于班长与战士，不能据比喻推出书记可个人命令一切。

| 怎样作出判断 | 原文定位 | 现代使用需补的条件 |
| --- | --- | --- |
| 依靠集体，问题公开讨论，成员交换信息 | 第一—三条，13333—13337行 | 查谁能提出议题、谁有最终决定权、分歧能否留下记录 |
| 不懂就向下级问，先分析再表态 | 第四条，13339行 | 原文允许军事紧急或情况已明的例外；现代调查也应与时限相配 |
| 抓中心，同时协调其他必要工作 | 第五—六条，13341—13343行 | 需要分别规定主攻成果与基础工作最低维持要求，而非平均分力或全部砍掉 |
| 用数量分析把握情况和界限 | 第七条，13345行 | 统计必须有口径、分母、期限与可信来源，不能用伪精确数字代替调查 |
| 事前说明议题并准备，简明表达 | 第八—九条，13347—13349行 | 用资料和待决事项支持会议，避免把会议本身当成成果 |
| 同意见不同的人合作，抑制骄傲和歌颂 | 第十—十一条，13351—13353行 | 不能只保留赞成者，也不能以忠诚取代事实判断 |
| 分析性质、成绩与缺点 | 第十二条，13355行 | 原文有革命与反革命的政治界限；不能直接移植为公司敌我，也不能将三七比例当作任意工作的固定评分 |

**结论依赖哪些条件**：成员有表达和信息获取条件，负责人尊重集体规则，执行人理解目标并能反馈；数据可核查；会议有准备，决定有人落实。关于权力约束的实际情况须另外取证，不能用“少数服从多数”的条文证明现实中不存在个人专断。

**适用边界**：现代可用在会议准备、团队决策、任务协调和数字口径。意见不同可能来自专业分工、利益冲突、信息差或真实的不确定性，不应预先定为政治立场错误。组织决策权与事实真伪分别处理；多数表决可以决定行动，却不使事实变真。

**本卡生成的调用规则**：会前给一页事实和待决问题；会上保留替代方案与关键异议；会后记录负责人、期限、依赖条件与复查点。评价决策时，既看结果，也查过程是否允许坏消息改变方案。
