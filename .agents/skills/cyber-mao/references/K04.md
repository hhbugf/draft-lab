# K04 论持久战：时间必须通过具体机制改变力量对比

**原文出处**：《论持久战》，题注1938年5月；附注说明为5月26日至6月3日在延安抗日战争研究会的讲演。基准《选集》TXT第5190—5721行，正文119个编号段及末段讲演结语，附注另列。当前使用整理收入《选集》的文本，不声称是未经修订的现场速记。

**当时解决什么问题**：全面抗战约十个月后，如何在严重损失、局部胜仗和对外援的期待之间判断战争前途；为什么不能由暂时弱势推出必亡，也不能由平型关、台儿庄等局部胜利推出速胜；如何把长期抗战变成实际行动，而非信心口号。对象是1930年代的中日战争，不是任何弱者的普遍成功公式。

**依据什么事实**：文中比较双方军事、经济与政治组织能力，国土与人口规模，战争性质、社会动员和国际关系；同时采用抗战十个月的经验、战争史类比和对未来的推断。必须区分这三种证据。日本兵力及资源的限制、中国地域与组织潜力，是文中的现实判断；国际援助进一步增强、日本国内变化等，则包含尚待实现的预测。不能把预测写成1938年已经发生的事实。

**结论依赖哪些条件**：有能维持抵抗的地域、人口、组织与补给；动员能够产生实际资源，内部合作能够维持；主观行动能增强自身并限制对方；国际力量变化有利于抗战。文本把若干趋势判断得很确定，这种确定性本身也应接受历史检查。原文第57—58段关于世界制度及永久和平的远景，不由中国抗战最终胜利自动得到证明。

**适用边界**：现代迁移只保留“资源能否支撑等待—等待期间有什么可验证的变化—变化能否改善目标达成条件”的关系。创业现金消耗、求职窗口与健康精力都可能随时间恶化。必须说明补给来源、变化机制、检查日期和退出条件。军事欺骗、敌我消灭、战时惩处、牺牲要求不能直接变成客户、同事、家人的相处手段。第81段把胜败与指挥正确错误联系得很强，现代评估仍须考虑随机性和识别困难，不能用结果倒推全部决策品质。

**本卡生成的调用规则**：遇到“再坚持多久”，先查持续成本、可支撑期限、学习或收入增长的证据。没有变化机制时，不以“持久战”给继续投入背书。区分可恢复的小实验与可能使整体失去生存条件的承诺。这是现代规则，不冒充原文结论。
